# APEX RUSH Online · Render Free

무료 단일 인스턴스용 서버 패키지. 환경 파일·계정 인증 정보는 포함하지 않습니다.
이 디렉터리를 GitHub 저장소 루트로 올린 다음 Render Blueprint로 render.yaml을 배포하거나 Web Service / Docker / Free로 생성합니다.
유료 인스턴스나 추가 데이터베이스는 선택하지 않습니다.
/api/health로 정상 실행을 확인합니다.
발급된 HTTPS 서버 주소를 https://apexracer.vercel.app의 온라인 서버 주소로 설정하고, 이후 해당 주소를 웹 빌드 기본값으로 연결할 수 있습니다.
최대 5분 모집, 2명 이상이면 15초 추가 모집 후 출발, 3랩 서버 순위 계산.
서버 재시작 시 메모리의 방 상태는 초기화됩니다. 무료 서버의 휴면·트래픽 제한이 적용됩니다.
